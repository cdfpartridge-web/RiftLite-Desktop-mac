# RiftLite v0.9.73 release - 2026-09-06

The user explicitly authorized a version bump and publication of updated Windows and macOS installers. **Windows v0.9.73 and macOS mac-v0.9.73 are now public, non-prerelease and Latest**, from the same immutable source commit. Public downloads and updater manifests have been independently verified.

## Source and scope

- New version: 0.9.73. Existing 0.9.72 tags and release assets remain immutable.
- Includes the committed Atlas Player-name fallback and maintenance checkpoint, followed by full build cleanup, deck-comparison/MP4 modularisation, signed artwork, parked Replay Coach implementation and in-client Atlas deck editing.
- Replay Coach remains hidden behind Coming Soon. Search Rules remains disabled.
- Customer notes: `release-notes-v0.9.73.md` and `RiftLite-v0.9.73-Whats-New.txt`; in-app highlights and build identity are aligned.
- Website artwork and Your Move work remain separate and undeployed. No website, Firestore or production replay-data changes are part of this release.
- Historical v0.9.70 documents, `tmp-app-diff.txt` and `tmp/` remain excluded from staging and preserved.

## Release method

Build fresh Windows artifacts from an isolated checkout of the final release commit with committed LF line endings. Run the full release gate, clean build, NSIS packaging, artifact verification, packaged startup and package-content audit. Build and verify x64/arm64 macOS DMG/ZIP artifacts on native GitHub runners. Use fixed new tags pointing to the same source commit and verify fresh public downloads and updater manifests after publication.

macOS retains the established ad-hoc signing process, without Apple notarization. Native startup covers the runner's host architecture; both architectures receive bundle, executable, FFmpeg, signature, DMG and updater checks.

Signed-in Atlas deck saving, actual tester-display acceptance and live gameplay validation remain explicitly pending. Publication must not be reported as completion of those checks.
